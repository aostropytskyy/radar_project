### lcd1:
#### LCD	Pi Zero W

CS	GPIO8 — pin 24
DC	GPIO25 — pin 22
RST	GPIO24 — pin 18
BLK	3.3 V — pin 17

### lcd2:
#### Second GC9A01	Pi Zero W
